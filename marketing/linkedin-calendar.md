# LinkedIn — Stratégie Commentaires 4 Semaines

**Principe validé** : commenter sur des posts de grandes organisations avec des données précises du dashboard → curiosité → clic profil → découverte du produit. Aucun lien externe. Aucune mention de marque dans le commentaire.

## Comptes prioritaires à suivre (activer notifications)

### Tier 1 — Volume + audience cible directe

`#Epidemiology` · `#GlobalHealth` · `#OutbreakResponse` · `#IHR2005` · `#OneHealth` · `#InfectiousDisease` · `#HealthSecurity` · `#GHSA`

## Template de commentaire (structure validée)

```
[Donnée précise du dashboard qui complète ou enrichit le post]

[Angle unique : tendance, comparaison historique, spread géographique, CFR, ou discordance entre sources]

[Offre de partage de données → ouvre la curiosité sans forcer]
```

**Exemples concrets :**

> Post WHO sur Mpox : "Les données ECDC de cette semaine montrent 47 nouveaux cas en RDC (+12% vs semaine précédente) et une extension vers 3 nouvelles zones de santé depuis le 14 juin. Je suis le spread en temps réel si ça vous est utile."

> Post Africa CDC sur choléra : "Les chiffres compilés depuis OMS + Africa CDC sur ce foyer donnent un CFR de 2,1% — dans la moyenne des épisodes sub-sahariens post-2015 (1,8-2,4%). La distribution géographique montre une concentration sur 2 provinces côtières. Je peux partager la carte si utile."

> Post ECDC CDTR : "Intéressant le lag entre le DON OMS (publié J+11 après détection) et le CDTR ECDC (J+16). Sur les 8 derniers épisodes de ce type, la moyenne est J+13. Les systèmes de surveillance précoce compensent partiellement — je suis ça sur plusieurs sources en parallèle."

## Règles strictes (rappel)

1. **Jamais de lien externe** dans le commentaire — pénalité algorithme LinkedIn
2. **Jamais de mention @HealthWatchGlobal** dans le commentaire — le profil fait le travail
3. **Data précise avant tout** — un chiffre vague ("les cas augmentent") ne génère pas de curiosité
4. **Fin = offre de partage** — "je peux partager / je suis ça en temps réel si utile" → crée la demande
5. **Si quelqu'un répond positivement** → DM avec lien direct vers la page dashboard de la maladie citée

---

## Workflow quotidien (10 min/jour)

1. Ouvrir LinkedIn feed
2. Chercher les comptes Tier 1 → voir s'ils ont posté dans les 24h
3. Vérifier le dashboard HealthWatch pour les données correspondantes
4. Écrire le commentaire (données précises + offre)
5. Si réponse → DM dans les 2h avec lien

**Volume cible** : 2-3 commentaires/semaine les 2 premières semaines, monter à 5/semaine ensuite.
